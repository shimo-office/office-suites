# shimo.net 场景清单与自然语言交互示例（15 个场景）

> 返回：[README](README.md) · [安装使用说明](安装使用说明.md)

只保留本机实测通过、CLI 已能跑的场景。所有场景共用一套登录态：凭据在 macOS Keychain，过期就地重登再重试本条，不重输网址。

**初始化（仅第一次）**：输入产品网址（客户私有部署域名）→ `GET /api/v1/users/me` 校验可达 → Chrome 登录 `{base}/login` → 保存 `config.json`（网址）+ Keychain（凭据）→ 就绪。网址默认 `shimo.net`，私有部署用 `SHIMO_NET_ORIGIN=https://客户域名`。

## 安全与资源说明（请 IT / 运维关注）

**1. 不支持彻底删除文件（安全要求）**
- CLI 不提供「彻底删除」能力：删除操作只把文件移入回收站，之后可以恢复。
- 确需彻底删除时，只能由有权限的人在石墨网页的回收站里手动操作，CLI 侧不做不可逆动作。
- 删除前会先确认目标对象，避免误删。

**2. Agent 操作会消耗大量服务器资源**
- 搜索、批量读取/导出、批量改权限、批量下载、周报汇总等操作，会持续调用服务端接口，产生计算、存储和带宽开销。
- 避免高频轮询、全量扫描、大批量并发；大文件夹先列目录再按需读取，不要整库导出。

**3. 给 IT / 运维的建议**
- 对 Agent 的调用做频率、并发数、单次批量规模上限，必要时在网关侧限流。
- 监控接口耗时、失败率、导出任务队列、CPU／内存／带宽峰值，发现异常及时限流或降级。
- 业务高峰期避让，批量任务放低峰执行；为每个账号或 Agent 设置独立的配额与告警。

## 二、自然语言怎么输入（句式小抄）

| 你想干什么 | 直接这样说 |
|---|---|
| 找 | 找一下… / 搜一下… / 有没有叫…的 / 上次那个…在哪 |
| 定位 | 这个在哪个文件夹 / 哪个空间里 |
| 看目录 | 我都有哪些空间 / 这个空间里有什么 / 列一下这个文件夹 |
| 交付 | 把这个文件导到… / 放到…空间 / 导入后发我链接 |
| 权限 | 设成企业内可评论 / 改成公开只读 / 谁能看 |
| 拉取 | 拉下来 / 下载到本地 / 归档一份 |
| 新建 | 新建一份空白文档 / 表格 / 幻灯片，叫… |
| 整理 | 改名成… / 批量去掉某个后缀 |
| 上传 | 传上去 / 放到… / 传到我桌面 / 传到 @别名 |
| 常用位置 | 以后叫它… / 记住这个文件夹 / @别名 |
| 删除 | 删掉 / 移到回收站 / 恢复 / 彻底删除 |
| 汇总 | 读一遍 / 总结重点 / 出个周报 |
| 巡检 | 哪些是私有的 / 哪些能公开访问 / 有没有外链 |

**提高命中率的小习惯**

1. 说**对象 + 动作**就够：“把《技术方案》导入 AI Solutions”比“帮我处理一下那个文件”准得多。
2. 文件夹/空间尽量给**链接或确切名字**，重名时我会列出来让你选。
3. 写操作（导入、改权限、删除）先告诉你**目标链接和影响范围**；不可逆操作**二次确认**。
4. 记不清名字就描述：“上周给客户的那份 PPT”“标题里有『私有化』的文档”。

## 三、对话示例（Agent 会话框里真实长什么样）

### 对话 A：找 → 拉取

> **你**：帮我找一下 AI Solutions 那个文件夹，把里面的东西拉下来

> **Agent**：搜到文件夹 **AI Solutions**（`https://shimo.net/folder/xxxx`）。里面有 5 项：4 份文档、1 个 HTML 附件，还有 1 份自检文档。要全拉，还是排除自检那份？

> **你**：排除自检的

> **Agent**：拉到 `./pull-demo` 了，4 个文件 + `manifest.json`。

### 对话 B：导入 → 问权限 → 设置

> **你**：把这个 md 导到 AI Solutions，给团队看

> **Agent**：导好了：**（自检）CLI 导入演示 · 可删**（链接 `https://shimo.net/docs/xxxx`），当前权限：私有。“给团队看”对应哪种？① 企业内只读 ② 企业内可评论 ③ 企业内可编辑 ④ 公开链接只读/可评论/可编辑

> **你**：②

> **Agent**：已设为**企业内可评论**，链接不变。

### 对话 C：权限巡检

> **你**：看看 AI Solutions 里哪些文件是公开的

> **Agent**：6 个里 1 个公开（可评论）。要把那 1 个收回成企业内只读吗？

> **你**：收回

> **Agent**：已收回为**企业内只读**。

### 对话 D：周报

> **你**：把这周 AI Solutions 里更新的文档读一遍，给我一页纸

> **Agent**：这周更新 3 份。一页纸：**完成**（3 条）/ **关键数字**（3 个）/ **风险**（2 条）/ **建议**（1 条），每条附原文链接。

### 对话 E：删除与恢复

> **你**：把刚才那份自检文档删了

> **Agent**：删了（进回收站，可恢复）。

> **你**：算了，恢复回来

> **Agent**：已恢复，链接不变。确认不要了说“彻底删除”，才会从回收站清掉。

### 对话 F：贴链接直接操作（最省事）

> **你**：https://shimo.net/docs/xxx 改成企业内可编辑，再读一下讲什么

> **Agent**：权限已改为**企业内可编辑**。正文 2 段，核心是……（引用原文，附链接）

## 四、边界（我会怎么处理）

1. **不替你猜权限**：导入后一定先问；批量改之前先给清单和结果预览。
2. **不可逆操作二次确认**：彻底删除、清空回收站。
3. **格式不支持就直说**：目前导入只支持 `md / doc(x) / xls(x) / ppt(x)`。
4. **权限不够如实说**：读不到的文件说“当前账号无权限”，不编内容。
5. **总结类**：结论标“已验证 / 待核实”，原文链接必附。

## 五、对应的 CLI 命令

13 个场景全部有命令（项目内 `./shimo-net/shimo`，安装后 `shimo-net`）：

| 场景 | 命令 |
|---|---|
| 1 搜索 | `search <关键词>` |
| 2 空间/目录 | `spaces`、`ls <链接>`（`--since 7d` 过滤） |
| 3 文件出处 | `info <链接>` |
| 4 导入+权限 | `import <文件> --to <链接>` + `share <链接> <模式>` |
| 5 拉取 | `pull <链接> --out <目录>` |
| 6 新建 | `new <名称> --type doc\|sheet\|slide --to <链接>` |
| 7 改名 | `rename <链接> <新名字>` |
| 8 删除/回收站/恢复/彻底删 | `delete` / `trash` / `restore` / `purge <guid> --yes` |
| 9 权限巡检 | `audit <文件夹>` |
| 10 批量改权限 | `share <链接1> <链接2> … <模式>` |
| 11 读正文摘要 | `read <链接> [--max-chars N]` |
| 12 周报 | `ls <链接> --since 7d` + `read` |
| 13 附件下载 | `get <链接> --out <目录>` |
| 14 上传 | `upload <文件> [--to desktop\|空间\|文件夹\|@别名]`（不给会列出位置） |
| 15 常用文件夹 | `fav add <别名> <链接> --note 特征` / `fav list` / `fav rm` / `fav show` |

通用：`whoami` / `doctor` / `schema` / `login` / `logout`；全局 `--json`。
