# shimo-net CLI 安装与使用说明

版本 0.8.0 · macOS 主支持 / Linux 实验 · Go 单二进制

---

## 1. 这是什么

`shimo-net` 是一个命令行工具，直连石墨 shimo.net（支持客户私有部署），把 15 个常用办公场景做成命令：找文件、看空间、上传、导入、拉取下载、权限、新建改名删除、读正文、常用文件夹别名等。

特点：

- **单二进制**，运行时不依赖 Python / Node；
- **CLI 直连**，不开端口、不跑常驻服务；
- 登录只需一次，会话存进 **macOS Keychain**，之后命令复用；
- 支持 `--json` 输出，方便 Agent / 脚本调用。

---

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | macOS（Apple Silicon / Intel）；Linux 实验性支持 |
| 运行时 | 不需要 Python / Node；从源码构建需要 Go 1.22+ |
| 浏览器 | Google Chrome / Chromium / Microsoft Edge（登录和 `open` 用） |
| 网络 | 能访问目标 shimo.net 或客户私有部署域名 |

检查：

```bash
ls /Applications/Google\ Chrome.app
go version   # 仅从源码构建时需要
```

## 3. 安装

### 3.1 从仓库安装（推荐）

```bash
git clone https://github.com/shimo-office/office-suites.git
cd office-suites
./install.command
```

安装器会：

1. 有 Go 时本地构建，否则下载最新 release 二进制；
2. 生成命令 `~/.local/bin/shimo-net`；
3. 如存在 `~/.dsh`，把技能装到 `~/.dsh/skills/shimo-net-cli`；
4. 跑一次 `doctor` 自检。

### 3.2 从源码构建

```bash
go build -trimpath -ldflags "-s -w" -o bin/shimo-net ./cli
bin/shimo-net version
```

### 3.3 仓库内直接运行（不安装）

```bash
./shimo help
```

### 3.4 确认命令可用

```bash
shimo-net version       # shimo-net 0.8.0
shimo-net doctor        # 查看 chrome / 凭据 / origin
```

如果提示 `shimo-net: command not found`，把 `~/.local/bin` 加进 PATH：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### 3.5 卸载

```bash
rm -f  ~/.local/bin/shimo-net
rm -rf ~/.shimo-net-cli             # 配置 / 登录态 / 浏览器配置（可选）
rm -rf ~/.dsh/skills/shimo-net-cli  # 技能（如果装过）
security delete-generic-password -s shimo-net-cli 2>/dev/null || true
```

## 4. 首次配置与登录

### 4.1 选择环境

默认连 `https://shimo.net`。优先写入配置：

```bash
shimo-net init --origin https://<客户域名>
```

`init` 会保存到 `~/.shimo-net-cli/config.json`，并校验接口可达。也可以临时用环境变量（优先级最高）：

```bash
SHIMO_NET_ORIGIN=https://<客户域名> shimo-net whoami
```

查看 / 修改：

```bash
shimo-net config show
shimo-net config set https://<客户域名>
```

登录页、API、输出里的链接都会用这个域名。

### 4.2 登录

```bash
shimo-net login
```

- 首次使用没有 `config.json` 时，会提示输入产品网址（默认 `https://shimo.net`）；
- 弹出一个**无地址栏的 Chrome 窗口**，停在 `{origin}/login`；
- 用你自己的账号登录（账密 / 扫码均可）；
- 成功后窗口自动关闭，会话写入 macOS Keychain；
- 之后 `shimo-net whoami` 确认账号：

```bash
shimo-net whoami
# 示例：张三 <zhangsan@example.com>（id 10000001）
```

### 4.3 登录过期

命令返回 401 / 提示未登录时：

```bash
shimo-net login        # 重新登录
# 然后重试刚才的命令，网址不需要重配
```

也可以在执行任意命令时加 `--relogin`：遇到 401 自动打开登录，成功后重试原命令。

## 5. 快速上手

```bash
# 找东西
shimo-net search "AI Solutions"
shimo-net spaces
shimo-net ls https://shimo.net/folder/xxxx

# 记一个常用文件夹，之后用 @别名
shimo-net fav add ai "https://shimo.net/folder/xxxx" --note "AI 方案常用"
shimo-net ls @ai

# 上传（原样云文件）与导入（转在线文档）
shimo-net upload 报告.pdf --to @ai
shimo-net import 周报.md --to @ai

# 打开 / 下载
shimo-net open <链接>
shimo-net pull @ai --out ./下载
```

## 6. 15 个场景与命令

| # | 场景 | 命令 |
|---|---|---|
| 1 | 搜索文件 / 文件夹 / 空间 | `shimo-net search "<关键词>"` |
| 2 | 我的空间 / 空间里有什么 | `shimo-net spaces`、`shimo-net ls <链接\|@别名>` |
| 3 | 文件类型 / 权限 / 所在路径 | `shimo-net info <链接\|@别名>` |
| 4 | 导入并设置权限 | `shimo-net import <文件> --to <位置>` 后 `shimo-net share <链接> <权限>` |
| 5 | 拉取文件夹到本地 | `shimo-net pull <链接> --out <目录> [--since 7d]` |
| 6 | 新建空白文档 / 表格 / 幻灯片 | `shimo-net new <名称> --type doc\|sheet\|slide --to <位置>` |
| 7 | 改名 | `shimo-net rename <链接> "<新名字>"` |
| 8 | 删除 / 回收站 / 恢复 | `shimo-net delete`、`shimo-net trash`、`shimo-net restore <guid>` |
| 9 | 权限巡检 | `shimo-net audit <文件夹\|@别名>` |
| 10 | 批量改权限 | `shimo-net share <链接1> <链接2> … <权限>` |
| 11 | 读正文 / 摘要 | `shimo-net read <链接> [--max-chars 12000]` |
| 12 | 周报 / 一页纸 | `shimo-net ls <链接> --since 7d` + `shimo-net read` |
| 13 | 附件 / 云文件下载 | `shimo-net get <链接> --out <目录>` |
| 14 | 上传（先问传到哪里） | `shimo-net upload <文件> [--to desktop\|空间\|文件夹\|@别名]` |
| 15 | 常用文件夹别名 | `shimo-net fav add <别名> <链接> --note 特征`；之后用 `@别名` |

其他：`init`、`config`、`whoami`、`doctor`、`schema`、`login`、`logout`；全局参数 `--json`、`--relogin`。

### 上传与导入的区别

| | `upload` | `import` |
|---|---|---|
| 结果 | 原样云文件（不改内容） | 转成在线文档 / 文稿 / 表格 / 幻灯片 |
| 链接 | `/files/<guid>` | `/docs`、`/docx`、`/sheets`、`/presentation/<guid>` |
| 适用 | 附件、压缩包、图片等 | md、doc(x)、xls(x)、ppt(x) |

`upload` 不给 `--to` 时会列出可选位置（桌面 / 空间 / 文件夹 / @别名），确认后再传。

## 7. 权限（7 档）

| 值 | 含义 |
|---|---|
| `private` | 私有（仅自己） |
| `enterprise_readonly` | 企业内只读 |
| `enterprise_commentable` | 企业内可评论 |
| `enterprise_editable` | 企业内可编辑 |
| `readonly` | 公开链接 · 只读 |
| `commentable` | 公开链接 · 可评论 |
| `editable` | 公开链接 · 可编辑 |

```bash
shimo-net share <链接> enterprise_commentable
shimo-net share <链接1> <链接2> readonly     # 批量
```

注意：后三种是**公开链接**，任何拿到链接的人都能访问；导入后先问清楚再设。

## 8. 常用文件夹别名（@别名）

```bash
shimo-net fav add market "https://shimo.net/folder/xxxx" --note "市场部常用"
shimo-net fav list
shimo-net fav show market
shimo-net fav rm market
```

- 别名支持中英文、数字、下划线、短横线，最长 40 字；
- 任何需要“链接 / guid”的参数都能换成 `@别名`；
- 存在 `~/.shimo-net-cli/favorites.json`，只有别名和链接，不含账号信息。

## 9. JSON 输出与退出码（给脚本 / Agent）

```bash
shimo-net search "关键词" --json
shimo-net whoami --json
```

- 成功：`exit 0`，stdout 为 JSON；
- 失败：`exit 1`，stderr 为 `{"ok":false,"error":"..."}`。

查看全部命令与参数结构：

```bash
shimo-net schema
```

## 10. 安全与资源说明（请 IT / 运维关注）

**1. 删除只进回收站，不支持彻底删除**

- CLI 的删除操作只把文件移入回收站，之后可以恢复；
- **不提供“彻底删除”**：确需彻底删除时，请到石墨网页的「回收站」里手动操作；
- CLI 不做不可逆动作，避免误删。

**2. Agent 操作会消耗大量服务器资源**

- 搜索、批量读取/导出、批量改权限、批量下载、周报汇总等会持续调用服务端接口，产生计算、存储和带宽开销；
- 避免高频轮询、全量扫描、大批量并发；大文件夹先列目录再按需读取，不要整库导出。

**3. 给 IT / 运维的建议**

- 对 Agent 的调用做频率、并发数、单次批量规模上限，必要时在网关侧限流；
- 监控接口耗时、失败率、导出任务队列、CPU / 内存 / 带宽峰值；
- 业务高峰期避让，批量任务放低峰执行；为账号 / Agent 设置独立配额与告警。

**4. 凭据怎么存**

| 内容 | 位置 |
|---|---|
| 会话 cookie | macOS Keychain（服务 `shimo-net-cli`，加密） |
| 账号信息 | 不在本地文件落盘；`whoami` 实时向服务端查询 |
| 常用位置 | `~/.shimo-net-cli/favorites.json`（别名/链接，无账号） |
| 浏览器会话 | `~/.shimo-net-cli/chrome-profile`（用于 `open` / 重新登录） |

不想在本机保留浏览器会话时，可删除 `~/.shimo-net-cli/chrome-profile`；CLI 命令仍可正常使用（`open` 需重新登录）。

## 11. 常见问题

| 现象 | 处理 |
|---|---|
| 未登录 / 401 | `shimo-net login`，成功后重试原命令 |
| 命令找不到 | 把 `~/.local/bin` 加进 PATH |
| 找不到 Go（源码构建） | 安装 Go 1.22+，或直接用 `./install.command` 下载二进制 |
| 找不到 Chrome | 安装 Google Chrome，或改默认浏览器为 Chromium / Edge |
| 链接点开还要登录 | 用 `shimo-net open <链接>`，走 CLI 的登录态浏览器 |
| 上传后不是在线文档 | `upload` 是云文件；要在线文档用 `import` |
| 格式不支持 | 导入仅支持 md / doc(x) / xls(x) / ppt(x) |
| 无权限 | 账号对目标文件/空间没有权限，换账号或让管理员授权 |
| 私有部署连不上 | 确认 `SHIMO_NET_ORIGIN` 正确、网络可达、证书有效 |
| 想彻底删除 | CLI 不提供，到石墨网页回收站手动删除 |
| 脚本解析失败 | 加 `--json`；错误信息在 stderr，退出码为 1 |
