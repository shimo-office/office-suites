# shimo-net CLI 安装与使用说明

最新版 · macOS / Linux / Windows · Go 单二进制

---

## 1. 这是什么

`shimo-net` 是一个命令行工具，直连石墨 shimo.net（支持客户私有部署），把 28 个常用办公场景和 50 项能力做成命令：找文件、看空间、上传、导入、拉取下载、权限、新建改名删除、读正文、常用文件夹别名等。

特点：

- **单二进制**，运行时不依赖 Python / Node；
- **CLI 直连**，不开端口、不跑常驻服务；
- 登录只需一次，会话存进 **macOS Keychain**（Windows 为 Credential Manager），之后命令复用；
- 支持 `--json` 输出，方便 Agent / 脚本调用。

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | macOS / Linux / Windows 10/11 |
| 运行时 | 不需要 Python / Node；从源码构建需要 Go 1.22+ |
| 浏览器 | Google Chrome / Chromium / Microsoft Edge（登录和 `open` 用） |
| 网络 | 能访问目标 shimo.net 或客户私有部署域名 |

检查：

```bash
ls /Applications/Google\ Chrome.app
go version   # 仅从源码构建时需要
```

## 3. 安装

### 3.1 从仓库安装（推荐）

**macOS / Linux**

```bash
git clone https://github.com/shimo-office/office-suites.git
cd office-suites
./install.command
```

**Windows（PowerShell）**

```powershell
git clone https://github.com/shimo-office/office-suites.git
cd office-suites
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装器会：

1. 有 Go 时本地构建，否则下载最新 release 二进制；
2. 生成命令：macOS/Linux 为 `~/.local/bin/shimo-net`，Windows 为 `%LOCALAPPDATA%\shimo-net\shimo-net.exe`；
3. 如存在 `~/.dsh`，把技能装到 `~/.dsh/skills/shimo-net-cli`；
4. 跑一次 `doctor` 自检。

### 3.2 从源码构建

```bash
go build -trimpath -ldflags "-s -w" -o bin/shimo-net ./cli
bin/shimo-net version
```

### 3.3 仓库内直接运行（不安装）

```bash
./shimo help
```

### 3.4 确认命令可用

```bash
shimo-net version       # 输出当前最新版版本号
shimo-net doctor        # 检查 runtime / chrome / origin / 凭据 / account，最后一行应为「结果：🟢 doctor: OK」
```

如果提示 `shimo-net: command not found`，把 `~/.local/bin` 加进 PATH：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### 3.5 卸载

```bash
rm -f  ~/.local/bin/shimo-net
rm -rf ~/.shimo-net-cli             # 配置 / 登录态 / 浏览器配置（可选）
rm -rf ~/.dsh/skills/shimo-net-cli  # 技能（如果装过）
security delete-generic-password -s shimo-net-cli 2>/dev/null || true
```

## 4. 首次配置与登录

### 4.1 选择环境

默认连 `https://shimo.net`。优先写入配置：

```bash
shimo-net init --origin https://<客户域名>
```

`init` 会保存到 `~/.shimo-net-cli/config.json`，并校验接口可达。也可以临时用环境变量（优先级最高）：

```bash
SHIMO_NET_ORIGIN=https://<客户域名> shimo-net whoami
```

查看 / 修改：

```bash
shimo-net config show
shimo-net config set https://<客户域名>
```

登录页、API、输出里的链接都会用这个域名。

### 4.2 登录

```bash
shimo-net login
```

- 首次使用没有 `config.json` 时，会提示输入产品网址（默认 `https://shimo.net`）；
- 弹出一个**无地址栏的 Chrome 窗口**，停在 `{origin}/login`；
- 用你自己的账号登录（账密 / 扫码均可）；
- 成功后窗口自动关闭，会话写入 macOS Keychain（Windows 为 Credential Manager）；
- 之后 `shimo-net whoami` 确认账号：

```bash
shimo-net whoami
# 示例：张三 <zhangsan@example.com>（id 10000001）
```

### 4.2.1 已经在 Chrome 登录过？

CLI 已支持免二次登录。只要本机 Chrome / Chromium / Edge / Brave 里已经登录 shimo.net，CLI 会在 Keychain 没有会话或返回 401 时自动复用浏览器会话，验证后写回 Keychain：

```bash
shimo-net session status --json     # 看会话来自 Keychain / 文件 / 浏览器
shimo-net session harvest --json    # 手动触发复用；--no-save 只验证
shimo-net open <链接>               # 专用浏览器注入完整 cookie jar
shimo-net open <链接> --default     # 系统默认浏览器（Chromium 内核时注入）
```

- 注入的是完整 cookie jar（`sid`、`smdev-ws-route`、`deviceId` 等），不是只注入 sid；
- 终端不会输出 cookie / sid；
- 默认浏览器不是 Chromium 内核（例如 Safari）时，会如实提示无法注入，需要在该浏览器里登录一次。

### 4.3 登录过期

命令返回 401 / 提示未登录时：

```bash
shimo-net login        # 重新登录（复用本机 Chrome 会话）
shimo-net login --new  # 切换账号：强制新登录，不复用本机会话
# 然后重试刚才的命令，网址不需要重配
```

也可以在执行任意命令时加 `--relogin`：遇到 401 自动打开登录，成功后重试原命令。

## 5. 快速上手

```bash
# 找东西
shimo-net search "AI Solutions"
shimo-net spaces
shimo-net ls https://shimo.net/folder/xxxx

# 记一个常用文件夹，之后用 @别名
shimo-net fav add ai "https://shimo.net/folder/xxxx" --note "AI 方案常用"
shimo-net ls @ai

# 上传（原样云文件）与导入（转在线文档）
shimo-net upload 报告.pdf --to @ai
shimo-net import 周报.md --to @ai

# 打开 / 下载
shimo-net open <链接>
shimo-net pull @ai --out ./下载
```

## 6. 当前场景与命令

| # | 场景 | 命令 |
|---|---|---|
| 1 | 搜索文件 / 文件夹 / 空间 | `shimo-net search "<关键词>"` |
| 2 | 我的空间 / 空间里有什么 | `shimo-net spaces`、`shimo-net ls <链接\|@别名>` |
| 3 | 文件类型 / 权限 / 所在路径 | `shimo-net info <链接\|@别名>` |
| 4 | 导入并设置权限 | `shimo-net import <文件> --to <位置>`；权限必须到石墨网页人工设置 |
| 5 | 拉取文件夹到本地 | `shimo-net pull <链接> [--out <目录>] [--since 7d]`（省略时 `./shimo-pull`） |
| 6 | 新建空白文档 / 文稿 / 表格 / 幻灯片 | `shimo-net new <名称> --type doc\|docx\|sheet\|slide --to <位置>`；`doc`=文档，`docx`=文稿 |
| 7 | 改名 | `shimo-net rename <链接> "<新名字>"` |
| 8 | 删除 / 回收站 / 恢复 | `shimo-net delete`、`shimo-net trash`、`shimo-net restore <guid>` |
| 9 | 权限巡检 | `shimo-net audit <文件夹\|@别名> [--limit 200]` |
| 10 | 批量改权限 | CLI 禁止处理；打开石墨网页逐项人工确认和设置 |
| 11 | 读正文 / 摘要 | `shimo-net read <链接> [--max-chars 12000]` |
| 12 | 周报 / 一页纸 | `shimo-net ls <链接> --since 7d` + `shimo-net read` |
| 13 | 附件 / 云文件下载 | `shimo-net get <链接> [--out <目录>]`（省略时 `./shimo-pull`） |
| 14 | 上传（先问传到哪里） | `shimo-net upload <文件> [--to desktop\|空间\|文件夹\|@别名]` |
| 15 | 常用文件夹别名 | `shimo-net fav add <别名> <链接> --note 特征`；之后用 `@别名` |
| 16 | 只看与我相关的内容 | `shimo-net phase2 <链接> --action mentions-list\|comments-list`；订阅用 `subscriptions` |
| 17 | 留痕与版本 | `shimo-net open <链接>` 后由 computer-use 操作历史面板 |
| 18 | 文字与段落 | `shimo-net open <链接>` 后由 computer-use 操作菜单和选区 |
| 19 | 文内表格与图片 | `shimo-net open <链接>` 后由 computer-use 插入、调整并截图 |
| 20 | 评论与提及 | `comments-list` 读取；添加评论和 @ 提及走页面操作 |
| 21 | 预览与打印 | `shimo-net open <链接>` 后由 computer-use 操作预览/打印 |
| 22 | 文档重排全文 | `shimo-net open <链接>` 后由 computer-use 调整标题、段落和页面样式 |
| 23 | 表格写入 | `phase2 --action sheet-update\|sheet-append\|sheet-insert\|sheet-delete` 直接调用表格 API |
| 24 | 表格整理 | `shimo-net open <链接>` 后由 computer-use 操作冻结、排序、筛选和单元格底色 |
| 25 | 表格清洗 | 删除重复项、分列、填充等通过表格页面操作 |
| 26 | 表格算与看数 | `shimo-net open <链接>` 后由 computer-use 操作公式、定义名称和透视表 |
| 27 | 表格校验与格式 | `phase2 --action sheet-format\|sheet-merge` 直接调用表格 API；数据验证仍用页面 |
| 28 | 表格输出 | 导出使用异步导出 API；打印用 `open` + computer-use |

其他：`init`、`config`、`whoami`、`doctor`、`schema`、`login`、`logout`、`open`、`phase2`、`subscriptions`；全局参数 `--json`、`--relogin`。

没有对应 API 的编辑功能固定转页面：所有 Agent 优先打开内联浏览器；没有内联浏览器时使用 `shimo-net open <链接>`，CLI 会从 Keychain 注入登录态，再由 computer-use 点击页面菜单、工具栏和选区并返回截图。`open --default` 只作为没有内联浏览器和 CLI 专用浏览器时的最后兜底。单元格历史必须先说明行号和列号；文件锁定、限制编辑、高级权限、成员级授权和彻底删除必须由人工在石墨网页操作。

### 上传与导入的区别

| | `upload` | `import` |
|---|---|---|
| 结果 | 原样云文件（不改内容） | 转成在线文档 / 文稿 / 表格 / 幻灯片 |
| 链接 | `/files/<guid>` | `/docs`、`/docx`、`/sheets`、`/presentation/<guid>` |
| 适用 | 附件、压缩包、图片等 | md、doc(x)、xls(x)、ppt(x) |

`upload` 不给 `--to` 时会列出可选位置（桌面 / 空间 / 文件夹 / @别名），确认后再传。

## 7. 权限（7 档）

| 值 | 含义 |
|---|---|
| `private` | 私有（仅自己） |
| `enterprise_readonly` | 企业内只读 |
| `enterprise_commentable` | 企业内可评论 |
| `enterprise_editable` | 企业内可编辑 |
| `readonly` | 公开链接 · 只读 |
| `commentable` | 公开链接 · 可评论 |
| `editable` | 公开链接 · 可编辑 |

```bash
权限变更不由 CLI 执行，请打开石墨网页人工确认和设置。
```

注意：后三种是**公开链接**，任何拿到链接的人都能访问；导入后先问清楚再设。

## 8. 常用文件夹别名（@别名）

```bash
shimo-net fav add market "https://shimo.net/folder/xxxx" --note "市场部常用"
shimo-net fav list
shimo-net fav show market
shimo-net fav rm market
```

- 别名支持中英文、数字、下划线、短横线，最长 40 字；
- 任何需要“链接 / guid”的参数都能换成 `@别名`；
- 存在 `~/.shimo-net-cli/favorites.json`，只有别名和链接，不含账号信息。

## 9. JSON 输出与退出码（给脚本 / Agent）

```bash
shimo-net search "关键词" --json
shimo-net whoami --json
```

- 成功：`exit 0`，stdout 为 JSON；
- 失败：`exit 1`，stderr 为 `{"ok":false,"error":"..."}`。

查看全部命令与参数结构：

```bash
shimo-net schema
```

## 10. 安全与资源说明（请 IT / 运维关注）

**1. 删除只进回收站，不支持彻底删除**

- CLI 的删除操作只把文件移入回收站，之后可以恢复；
- **不提供“彻底删除”**：确需彻底删除时，请到石墨网页的「回收站」里手动操作；
- CLI 不做不可逆动作，避免误删。

**2. Agent 操作会消耗大量服务器资源**

- 搜索、批量读取/导出、批量下载、周报汇总等会持续调用服务端接口，产生计算、存储和带宽开销；权限变更不由 CLI 执行。
- 避免高频轮询、全量扫描、大批量并发；大文件夹先列目录再按需读取，不要整库导出。

**3. 给 IT / 运维的建议**

- 对 Agent 的调用做频率、并发数、单次批量规模上限，必要时在网关侧限流；
- 监控接口耗时、失败率、导出任务队列、CPU / 内存 / 带宽峰值；
- 业务高峰期避让，批量任务放低峰执行；为账号 / Agent 设置独立配额与告警。

**4. 凭据怎么存**

| 内容 | 位置 |
|---|---|
| 会话 cookie | macOS Keychain（服务 `shimo-net-cli`，加密）；Windows Credential Manager（target `shimo-net-cli`） |
| 账号信息 | 不在本地文件落盘；`whoami` 实时向服务端查询 |
| 常用位置 | `~/.shimo-net-cli/favorites.json`（别名/链接，无账号） |
| 浏览器会话 | `~/.shimo-net-cli/chrome-profile`（用于 `open` / 重新登录） |

不想在本机保留浏览器会话时，可删除 `~/.shimo-net-cli/chrome-profile`；CLI 命令仍可正常使用（`open` 需重新登录）。

## 11. 常见问题

| 现象 | 处理 |
|---|---|
| 未登录 / 401 | `shimo-net login`，成功后重试原命令 |
| 命令找不到 | macOS/Linux 把 `~/.local/bin` 加进 PATH；Windows 重开终端（安装器会写用户 PATH） |
| 找不到 Go（源码构建） | 安装 Go 1.22+，或直接用 `./install.command` 下载二进制 |
| 找不到 Chrome | 安装 Google Chrome，或改默认浏览器为 Chromium / Edge |
| 链接点开还要登录 | 用 `shimo-net open <链接>`，走 CLI 的登录态浏览器 |
| 上传后不是在线文档 | `upload` 是云文件；要在线文档用 `import` |
| 格式不支持 | 导入仅支持 md / doc(x) / xls(x) / ppt(x) |
| 无权限 | 账号对目标文件/空间没有权限，换账号或让管理员授权 |
| 私有部署连不上 | 确认 `SHIMO_NET_ORIGIN` 正确、网络可达、证书有效 |
| 想彻底删除 | CLI 不提供，到石墨网页回收站手动删除 |
| 脚本解析失败 | 加 `--json`；错误信息在 stderr，退出码为 1 |

## 12. 目录与文件

| 路径 | 作用 |
|---|---|
| `~/.local/bin/shimo-net` | 命令入口（Go 二进制） |
| `~/.shimo-net-cli/` | 配置 / 登录态 / 浏览器配置 |
| `~/.shimo-net-cli/config.json` | 产品网址（origin） |
| `~/.shimo-net-cli/credentials.json` | 凭据元数据（macOS 时 cookie 在 Keychain） |
| `~/.shimo-net-cli/favorites.json` | 常用位置别名 |
| `~/.dsh/skills/shimo-net-cli/` | DSH 技能（如安装了 DSH） |

> Windows 对应路径：`%APPDATA%\shimo-net-cli\`（config / credentials / favorites）、`%LOCALAPPDATA%\shimo-net\shimo-net.exe`。
