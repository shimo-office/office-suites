# 全局反例验收范围与证据边界

本页为可移植公开摘要。完整历史审计、原始失败及后续修复记录保留在本地验收档案；旧的阶段实施缺口表不是当前能力清单。最新判定见[三期验收记录](../phase3-acceptance.md)及[发布前验收补充](../release-acceptance-2026-11-19.md)。

## 原验收要求

| 项目 | 必须证明的行为 | 证据边界 |
|---|---|---|
| G1 权限 | 无编辑权限时写前拒绝，内容保持不变。 | 实际viewer文稿不能导出样本在before-export拒绝；不冒称可导出的viewer分支也已测试。 |
| G2 协作 | 不同账号正在编辑时中止；退出第二账号后正常编辑应可成功。 | 以真实服务端协作名单、真实退出码、前后导出和单账号对照证明；同一账号多个窗口不算双账号。 |
| G3 结果校验 | 受理后no-op、空导出或结果不符必须非0且无verified:true。 | 真实服务结果、受控代理故障注入、模拟HTTP/CDP分别记录，不混为自然线上故障。 |
| G4 写后异常 | 说明可能已写入及失败阶段，--relogin不得重放追加、删除或发布。 | 正式二进制、实际请求/内容计数与独立读回绑定；导出请求不当作内容写入。 |
| G5 页面物证 | 登录页、空白页、SDK未就绪不能作为成功物证；给出具体失败及恢复条件。 | 原图、截图失败和等待超时均如实保留；读取可有限重试，写入不自动重放。 |

## 回归入口

- [生产命令的全局负例测试](../../cli/phase3_global_negative_test.go)覆盖表格模拟HTTP受理无效、空导出和写后验证异常。
- [发布负例测试](../../cli/phase3_global_publish_negative_test.go)覆盖模拟CDP/HTTP条件下的发布失败、权限和重放保护。
- [表单截图校验](../../cli/phase3_global_form_screenshot_test.go)覆盖真实图片解析、全白拒绝和保留原始诊断图。历史PNG对照是离线重验，不是新截图。

这些可重复的离线测试证明生产代码路径，不单独增加线上通过数。实际线上/注入验收的最终状态及限制由发布前验收补充记录；不从测试文件存在推断验收已完成。

## 历史事实保留

曾出现结果与请求不一致、发布已受理后fresh-profile失败、空白编辑器及COS资源403等真实异常。每次原始退出码和构建哈希保留；后续只读恢复不改写原失败，不以真实403冒充401，也不以旧运行哈希冒充最终构建。原始证据仅在本地档案，不提供不存在的源码仓库链接。
