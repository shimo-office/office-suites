# 豆包工作 接入说明

**简体中文** · [English](../en/agent/doubao.md) · [助手入门](README.md)

本页只说明 豆包工作 的入口和接入范围。安装请求、登录和第一个任务统一见[四步教程](README.md)。

<a id="第-1-步打开助手"></a>

## 打开本地任务

打开豆包桌面端，进入“工作”，选择“本地电脑”。云端任务不能直接使用本机 CLI 和登录状态。

## 接入范围

Agent 在当前本地任务中读取同版本技能说明并调用 CLI；本流程不要求独立技能目录，也不承诺跨会话永久保留。新任务没有保留说明时，由 Agent 重新读取。

<a id="第-2-步发送安装请求"></a>
<a id="第-3-步按需登录或授权"></a>

## 开始使用

将[通用安装请求](README.md#第-2-步把这段话发给-agent)发给当前助手，按提示完成登录或授权。Agent 核对 **程序可运行、技能已接入、账号可用** 后，即可用自然语言发起任务。
