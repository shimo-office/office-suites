# Codex 接入说明

**简体中文** · [English](../en/agent/codex.md) · [助手入门](README.md)

本页只说明 Codex 的入口和接入范围。安装请求、登录和第一个任务统一见[四步教程](README.md)。

<a id="第-1-步打开助手"></a>

## 打开本地任务

打开 Codex 桌面端、IDE 或 CLI 中能执行本机命令的任务，选择工作目录。

## 接入范围

Agent 核对当前客户端实际加载的技能位置与生效范围。需要访问系统凭据或写入技能目录时，按客户端提示授予必要权限；只有当前会话无法刷新技能时才新开会话。

<a id="第-2-步发送安装请求"></a>
<a id="第-3-步按需登录或授权"></a>

## 开始使用

将[通用安装请求](README.md#第-2-步把这段话发给-agent)发给当前助手，按提示完成登录或授权。Agent 核对 **程序可运行、技能已接入、账号可用** 后，即可用自然语言发起任务。
