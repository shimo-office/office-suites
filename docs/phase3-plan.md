## 真实完成的判定

每项都需要命令、数据、物证三层证据，并关联同一文件 GUID、同一次执行和具体目标对象。HTTP 200/204、SDK 方法存在、工具栏状态、XML 中任意位置存在一个样式节点，都不是完成证据。

1. **命令层**：保存实际命令、payload、CLI 构建标识、运行时间、退出码、方法及原始结果。失败返回非 0；部分动作已生效但验证失败时明确指出阶段，禁止自动重放非幂等动作。
2. **数据层**：按目标段落、单元格、形状、数据表、字段或题目 ID 核对请求结果；结构修改比较前后差异。先验证全部入参、目标类型及编辑权限，再产生写入。按需求页脚，其他用户正在编辑时中止并提示重试；不能验证该前提时不得宣称完整验收通过。
3. **物证层**：保存导出文件、结构断言及真实页面截图；刷新或重新打开后再验一次持久化。截图需包含目标对象并排除登录页、加载页和空白页。PDF 打印、媒体下载、答卷导出必须有实际文件，打开面板不能算完成。
4. **覆盖层**：一个功能行包含的全部子动作均通过才算该项通过。例如“插删行列、合并拆分、均分”不能由一次插行样例代替；合并后拆分要各有中间证据。

未执行记为“待测”；真实执行未达断言记为“失败”；明确环境、权限或服务能力限制记为“阻塞”，附恢复条件。只有三层证据齐全且所有断言通过才记为“通过”。Mock、本地示例文件、演示视频仅证明对应局部，不增加线上通过数。

## 分批验证重点

### A：文稿（9 项）

- 字符/段落格式核对目标文本的有效属性，必要时解析样式继承，不能仅扫描全包节点数量。
- 表格结构按每次操作验证行列、跨度、目标文本和宽高；图形按媒体关系 ID、位置、尺寸、环绕、旋转和样式验证。
- 页面设置核对单位换算；查找替换记录前后计数；页面定位必须有目标页截图。
- @ 提及核对真实用户引用，不能只写入普通 `@姓名` 字符串。默认测试当前用户自己；向他人通知须有明确收件人授权。

### B：幻灯片（10 项）

- 解析 `presentation.xml` 和关系文件确定实际页序、母版/主题/版式关系；不能按 ZIP 文件名数量推断操作效果。
- 图形和文本验证指定对象，表格验证单元格结构；媒体验证实际资源和可播放性，动画验证时序与对象引用并预览。
- 打印必须生成可读 PDF，核对页数与渲染内容；打开打印面板不算成功。

### C：应用表格/表单（9 项）

- 数据表、字段、记录、视图和图表分别按 ID 读回；新增记录精确计数，条件更新证明未命中记录保持不变。
- 关联字段须保存真实关联关系，图表需绑定数据源并验证汇总值；静态文字或图片不算能力实现。
- 表单分别验证题序、题型、选项和两个逻辑分支；截止时间固定为 Asia/Shanghai；发布链接须进入真实填写页。
- 使用三份已知测试答卷验统计和 CSV 内容。权限扩大或敏感操作仍遵守人工边界。
