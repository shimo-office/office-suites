# 教程配图

## 当前使用流程

`common/agent-journey.svg` 是可编辑源图，`common/agent-journey.png` 是其导出图。图片与当前用户教程的四步一致：打开助手、发安装请求让 Agent 自动配置、按需登录授权、自然语言办公。

图中明确标注“操作流程示意 · 非客户端截图”，不用于证明程序安装或客户端验收成功。教程同时保留文字步骤，图片加载失败也能继续操作。

## 历史界面示意

其他图片逐字迁自 `docs/tutorials/images/`，内容未改动。它们是旧版客户端的 H5 界面还原，部分文件名带 `real-` 也不代表当前真实截图。新用户教程不再用它们指引现版本的点击位置；历史上下文见 [Agent 连通记录](../../agent/validation.md)。

旧目录的同字节副本保留已发布的图片链接。内部能力测试截图独立存放在 `docs/internal/images/`。
